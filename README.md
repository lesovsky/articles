# articles

Материалы к моим статьям: тексты, скрипты экспериментов, сырые данные и код,
которым построены графики. Идея простая — если в посте есть числа, здесь должно
лежать всё, чем их можно перепроверить или повторить.

Каталоги называются `<год>-<месяц>-<тема>`.

| Каталог | О чём | Публикация |
|---|---|---|
| [2026-08-pg19-async-io](2026-08-pg19-async-io/) | Асинхронный ввод-вывод в PostgreSQL 18/19: что даёт апгрейд на дефолтах, что даёт настройка и где не даёт ничего | *готовится* |

## Что внутри каждого каталога

- `*.md` — текст статьи;
- `ROADMAP.md` — план работы со всеми поворотами по ходу дела, включая гипотезы,
  которые не подтвердились;
- `RESULTS.md` — все измерения с методикой;
- `scripts/` — скрипты стенда, в порядке запуска;
- `data/` — сырые результаты прогонов;
- `charts/` — графики и генератор к ним.
